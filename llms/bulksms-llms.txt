# BulkSMS.com

> Global SMS messaging platform for businesses — send and receive SMS in 200+ countries via API or web app.

BulkSMS.com is a leading SMS communications platform used by businesses worldwide to send and receive text messages at scale. Founded in 2000, BulkSMS provides reliable SMS delivery to over 200 countries through direct connections to mobile network operators.

The platform offers multiple ways to send SMS: a powerful HTTP-based API for developers, a web application for non-technical users, and email-to-SMS integration. Features include two-way messaging, message scheduling, sender ID customisation, Unicode support, and automated responses.

BulkSMS serves a wide range of industries including healthcare, education, logistics, financial services, and marketing, with both transactional and promotional messaging use cases.

## Pricing

- [SMS Pricing](https://www.bulksms.com/pricing/): Per-message pricing by destination country.
- Pricing bundle JSON: `https://www.bulksms.com/pricing/{currency}.json`, where `{currency}` is `eur`, `usd`, `gbp`, or `zar`.
- Destination coverage and credit cost JSON: `https://www.bulksms.com/coverage/country/?destinationCountry={ISO2}&customerCurrency={CURRENCY}`.
- VAT rates JSON: https://www.bulksms.com/pricing/vat-rates.json
